# ssbhesabfa 2.3.49

Choose the Qestyar installment accounting method for each gateway in Payment methods. **Bank receipt with fee calculation** uses the configured bank account and the existing fee calculation. **Gateway receivables and fee expense** records the verified receipt in receivables and posts the gateway fee to expenses.

The form shows fields for the selected method and keeps settings for the other method. Gateways retain the previous choice until configured individually. Receipts that already have an accounting plan continue with that plan when retried.
